# Instructions for AI coding assistants

This is the HS SDK kit. To integrate it into a native TikTok mini game, read
[README.md](README.md) in this folder first and follow its section
"You (the AI assistant): your instructions". Ask the user the listed questions
before writing code. If the game already has a `hs-game.js`, this is an
UPGRADE — follow the README's upgrade steps, do not re-integrate. To make the
zip for TikTok ("build tiktok"), follow the README's "When the user wants to
upload to TikTok". Never ask for or write the TikTok Client Secret.
